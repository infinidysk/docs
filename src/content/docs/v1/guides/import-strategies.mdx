Choose how Radarr and Sonarr import completed jobs. Set this under **Settings → SABnzbd → Import Strategy**.

<Tabs>
<TabItem label="Symlinks — Plex">

Best when the media server needs real filesystem entries (classic Plex libraries).

1. Set **Rclone Mount Directory** to the path where the WebDAV mount is visible inside the Arr containers (e.g. `/mnt/remote/nzbdav`). It must be the same absolute path in every Arr container.
2. Run an [rclone sidecar](/v1/guides/mounting-webdav/) with `--links` so `*.rclonelink` files become symlinks into `/.ids`.
3. Point Arr root folders at paths that see those symlinks.

A bounded rclone VFS cache can smooth seeking without storing full media forever.

</TabItem>
<TabItem label="STRM — Emby/Jellyfin">

Best when the media server can play `.strm` URLs.

1. Set **Completed Downloads Dir** to a path shared with Arr (e.g. `/mnt/completed-downloads`).
2. Set **Base URL** to an infinidysk URL the media server can reach (HTTPS recommended).
3. Skip the rclone FUSE mount — no `/dev/fuse` required.

STRM files contain authenticated streaming URLs; keep Base URL and WebDAV credentials correct.

Jellyfin fills in duration and audio/subtitle languages for STRM items only after first playback —
see [Media servers](/v1/guides/media-servers/#emby-jellyfin).

</TabItem>
</Tabs>

## Path consistency

The completed path infinidysk reports must appear **at the same absolute path** inside the Radarr and Sonarr containers. Map volumes identically.

## Switching strategies

Maintenance tools can convert STRM → symlinks or recreate STRM sidecars — see [Maintenance](/v1/configuration/maintenance/). Back up first.
