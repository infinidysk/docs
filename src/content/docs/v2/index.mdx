infinidysk 2.x is a from-scratch rewrite of infinidysk in Rust. It keeps what Sonarr, Radarr and your media server talk to (the SABnzbd API and the WebDAV paths) and replaces everything behind it.

<Aside type="caution" title="Beta">
2.x is in beta. Expect some bugs, and keep your 1.x install and its config until you are happy. 1.x stays supported with bug fixes while 2.x matures.
</Aside>

## What changes from 1.x

<CardGrid>
	<Card title="Built-in mount" icon="seti:folder">
		2.x mounts the library itself over FUSE. No rclone sidecar, no RC notifications, no VFS cache flags.
	</Card>
	<Card title="One port" icon="random">
		The UI, the SABnzbd API and WebDAV all share port 3000.
	</Card>
	<Card title="Lighter" icon="rocket">
		Starts in under half a second and uses about a third of the CPU per GB streamed. See the [comparison](/#what-changes-in-2x).
	</Card>
	<Card title="Provider catalog" icon="list-format">
		Pick your provider from a catalog. Hostname, port and backbone come from the profile.
	</Card>
</CardGrid>

## Image

`ghcr.io/infinidysk/infinidysk-next`, Linux x64 and arm64.

| Tag | What it is |
|-----|------------|
| `v2.0.0-beta.N` | A beta release. Pin one of these to stay put. |
| `edge` | Every change on `main`, untested. May be broken. |
| `sha-<commit>` | One exact build, for reproducing a bug. |

There is no `latest` tag on purpose, so nothing upgrades onto the beta by accident. When 2.0 ships it moves to the main `infinidysk` image and this one stops updating.

## Not in 2.x yet

These 1.x features are missing in the beta. The upgrade report lists every setting it could not carry over.

- PAR2 reconstruction during repair
- Stremio and addon routes, search, indexers and Prowlarr
- Backup and restore
- Rclone RC notifications (not needed with the built-in mount)
