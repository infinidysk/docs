infinidysk 2.x is infinidysk (formerly NzbDAV) rewritten from scratch in Rust. It keeps what Sonarr, Radarr and your media server talk to (the SABnzbd API and the WebDAV paths) and replaces everything behind it with one native binary.

<Aside type="caution" title="Alpha">
2.x is in alpha. Expect bugs, and keep your 1.x install and its config until you are happy. 1.x stays supported with bug fixes while 2.x matures. The 2.x source code becomes available once 2.x reaches beta.
</Aside>

## What changes from 1.x

<CardGrid>
	<Card title="Built-in mount">
		2.x mounts the library itself over FUSE. No rclone sidecar, no RC notifications, no VFS cache flags.
	</Card>
	<Card title="One port">
		The UI, the SABnzbd API and WebDAV all share port 3000.
	</Card>
	<Card title="Written in Rust">
		No runtime and no garbage collector. Starts in under half a second and uses under a third of the CPU per GB streamed. See [why Rust](/v2/whats-new/#why-rust).
	</Card>
	<Card title="Provider catalog">
		Pick your provider from a catalog. Hostname, port and backbone come from the profile.
	</Card>
</CardGrid>

Some 1.x features are not in 2.x yet. [What's new in 2.x](/v2/whats-new/) lists every difference and the benchmark results.

## Image

`ghcr.io/infinidysk/infinidysk-next`, Linux x64 and arm64.

| Tag | What it is |
|-----|------------|
| `edge` | The latest 2.x build, updated with every change. The docs use this tag during the alpha. |
| `v2.0.0-alpha.N` | One alpha release. |
| `sha-<commit>` | One exact build, for reproducing a bug. |

There is no `latest` tag on purpose, so nothing upgrades onto a pre-release by accident. When 2.0 ships it moves to the main `infinidysk` image and this one stops updating.
